How to use
  • Load a page and map with the extension popup: Pick → Validate (or use Auto Map).
  • Send with Enter; Shift+Enter inserts a newline. A Send icon button is also available on some pages.
  • Toggle “Simulate replies” on a page to get a canned response like “You said <text> — what do you mean?”
Tips
  • For Enter-based submit, at the Send stage press the actual key combo (Enter/Ctrl+Enter).
  • History containers expose new messages so MutationObserver can detect appends.
